moonloader-scripts

  • Various useful moonloader lua scripts for SA-MP multiplayer
  • The presented systems were developed or improved by me, and implemented in working projects. Moonloader is a mod for the GTA San Andreas game, aiming to become a complete modern replacement for CLEO. It introduces the ability to load Lua scripts into the game, has all the functionality of the game's opcodes, the CLEO 4 library, the SAMPFUNCS 5.4+ plugin, SAMP.Lua and adds its own set of new features for development.
  • GitHub Download

Mapping Toolkit

  • Toolkit for mappers (SA-MP)
  • The toolkit gives you more options for mapping and developing your projects. To manage all features, a convenient graphical interface is provided on imgui. The toolkit provides additional functions for working with textures and objects, fixes some bugs in the game, and supplements server commands and dialogs. The functionality is quite extensive and is updated regularly. Designed for TRAINING SANDBOX.
  • GitHub Download

MP Helper

  • Assistant for event-makers (SA-MP)
  • The helper is intended for event organizers. Contains many functions for preparing and holding events in SA:MP. The script is supported for TRAINING SANDBOX and Absolute Play. May work on other projects, but some functionality may not be available.
  • GitHub Download

MTOOLS

  • GTA SA:MP mapping toolkit and GUI for Texture Studio
  • MTOOLS is a filterscript that complements Texture Studio and provides a classic dialog interface. This tools gives mappers more features to be more productive. MTOOLS is more familiar to fans of in-game mapping. Visit the wiki to learn more.
  • GitHub Download

useful-samp-stuff

  • Various useful filterscripts, includes and systems for SA-MP multiplayer
  • Various useful stuff and systems for SA-MP multiplayer. The presented systems were developed or improved by me, and implemented in working projects. The filterscripts are written in the Pawn language. To build from sources, you will need the Pawn Community Compiler. If you use VSCode install Pawn tools for vscode.

samp-essentials

  • A pack of necessary libs for the correct operation of SA:MP and mods
  • A pack of necessary libs for the correct operation of GTA San Andreas Multiplayer (SA-MP) and mods. Repository forked form JuniorDjjr sa-essentials-pack. This set is wider than the original one, but does not contain fixes and third-party mods! Only the original versions of the libraries are collected here.
