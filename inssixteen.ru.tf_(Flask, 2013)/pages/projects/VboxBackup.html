VboxBack v0.1.1

16.03.2013 Тестовая версия

API для резервного копирования виртуальных машин VirtualBox
Простая утилита которая помогает быстро создавать и восстанавливать резервные копии жёстких дисков vdi и vdmk. А также вести их учёт с помощью базы данных sqlite
Программа написана на Python и использует модули доступные "из коробки".Может быть портирована под любую операционную систему.На данный момент не используются SDK поставляемый Oracle. Тестировалось только на Linux но должно работать и на windows XP.Поддержка Windows7 планируется в версии 0.2 Необходим Python 2.7 версия OracleVirtualBox не важна.

Установка и настройка:
Распакуйте архив с программой в папку с виртуальными машинами VirtualBox Откройте в текстовом редакторе VBOXBackup.py и замените:
VboxMachinesPath = current_directory на VboxMachinesPath = "путь_к_папке_виртуальных_машин"

Также можно заменить DATABASE = os.path.join(CD, "machines.db") на DATABASE = "новый_путь_к_базе_данных". Здесь мы указываем место где будет харниться база данных machines.db (По умолчанию в текущей папке вместе с программой) Будьте осторожны если вы не до конца понимаете зачем это нужно то ничего здесь не меняйте!

Настройка завершена можно начинать работать с RunVboxBackupCLI. При первом запуске нужно создать базу данных всех виртуальных машин. В консоли набираем: 

python RunVboxBackupCLI.py --initdb
Появляется база данных machines.db.Теперь можно создать бэкапы для всех найденных машин командой. 

python RunVboxBackupCLI.py --backup -a
Бэкапы упаковываются в tar.gz архив в папке виртуальной машины рядом с оригинальым vdi или vdmk образом. Извлечь бэкап можно по имени машины из базы данных командой: 

python RunVboxBackupCLI.py --restore -n "windows_xp"

"windows_xp" это условное имя виртуальной машины которое было сгенерировано автоматически. Имена аналогичны с папкой в которой храняться файлы машины. Имена виртуальных машин хранятся в базе machines.db в колонке name (3-ей). В консоли имена и пути лучше брать в двойные кавычки это помогает избежать неожиданных проблем.

Аналогично можно создавать бэкап для одной машины командой: 

python RunVboxBackupCLI.py --backup -n "windows_xp"

Примеры использования API

Первый запуск: Создаст базу данных в которой будет храниться записи о виртуальных машинах 

import VBOXBackup as API
from VBOXBackup import DATABASE
from VBOXBackup import VboxMachinesPath
base = API.db()							
base.create_db(DATABASE,VboxMachinesPath)
1.Импортируем VBOXBackup.py присваиваем ему имя API
2-3.Импортируем константы
4.Подключаем класс для работы с базой данных
5.Вызываем функцию для создания базы данных в которую передаём (путь_к_базе,путь_к_папке_машин)

Появляется база данных sqlite machines.db . Теперь можно создать бэкапы для всех найденных машин 

import VBOXBackup as API
from VBOXBackup import DATABASE
backup = API.backup()
backup.backup_all_machines(DATABASE)
Или для одной машины.Замените VboxMachineName на имя вашей машины (из базы данных).

import VBOXBackup as API
from VBOXBackup import DATABASE
VboxMachineName = 'windows_xp'
backup = API.backup()
backup.backup_by_name(VboxMachineName)
Для восстановления из бэкапа: 

import VBOXBackup as API
VboxMachineName = 'windows_xp'
backup = API.backup()
backup.restore_machine(VboxMachineName)
Рекомендую для просмотра базы данных программу sqlitebrowser
Используйте кодировку UTF-8
