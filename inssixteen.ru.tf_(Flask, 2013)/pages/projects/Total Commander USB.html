Total Commander USB

Портативная сборка Total Commander предназначена для запуска с флешки или liveCD, не требовательна к памяти.(Русский присутствует).В сборку включены:

Плагины для чтения iso,img,msi,wcx,doc,pdf,db,swf форматов
Плагины для чтения NsCopy(чтение данных с плохих носителей),ex2fs(Чтениеразделов linux ext2)
Работа с архивами 7z,rar,cab,zip,ace
Включен легкий текстовый редактор AkelPad
NirCmd - Мощная консольная утилита позволяющая выполнять много полезных задач без
интерфейса.Поддерживает работу с реестром,ini-файлами,метевыми подключениями,сеансами,ярлыками..
TC_start - Запуск Total Commander с дополнительными настройками(Отображение скрытых файлов,активация вкладок, отображение значков носителей, крупные значки, включение русского меню и многое другое.) unpack_settings - распаковщик этих дополнительных настроек(можно изменить 7zip'ом)
