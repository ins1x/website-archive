Renameimages 0.2.3

Renameimages - python скрипт для для группового переименования изображений случайными именами. 

-d, --daemon Следить в каталоге за появлением новых файлов и переименовывать их
-r, --recursively Рекурсивно обойти папку
-f FOLDER, --folder FOLDER Папка для поиска файлов
